# ForkSight

A pallet detector that finds the two fork pockets on a pallet face, written
without a vision library. Every stage is implemented here: the Gaussian, the
Sobel, the non maximum suppression, the hysteresis, the integral image behind
the adaptive threshold, the union find behind connected components, and the
Hough accumulator.

I wrote it that way on purpose. Calling four library functions in a row teaches
you the order of the pipeline and nothing about why each stage exists.

## The idea

A pallet face is not a hard shape to describe. It is a bright board with two
dark pockets that are the same size, sit at the same height, and have a centre
block between them. Almost the whole detector is that sentence turned into
filters:

1. blur, to stop the noise from producing edges
2. adaptive threshold against a local mean, which gives the dark regions
3. connected components, with area, aspect ratio and extent per region
4. drop regions that cannot be a pocket on geometry alone
5. pair the survivors: similar height, similar area, aligned centres, and a gap
   between them in the right range relative to their width
6. run Canny and a Hough transform over the same frame to recover how far off
   level the face is

Step 5 is what carries the false positive rate. Steps 1 through 4 will happily
hand you a shadow.

## Why the threshold is adaptive

The renderer lights the floor with a vertical gradient, so the top of the frame
is darker than the bottom. There is no single global cut that finds a dark patch
near the top without also swallowing the entire bottom half. `test-regions.js`
asserts exactly that: it constructs the failing case for a global threshold and
then shows the local mean version separating both patches cleanly.

The local mean comes from an integral image, so the window size does not change
the cost per pixel. That matters here because the window has to be wide enough
to always contain some of the bright face. My first version used a radius of 14,
which is smaller than a pocket, so the interior of a large pocket was compared
against a window made entirely of pocket, and only the rim survived. Recall was
0.41. Widening the window fixed it.

## Ground truth

There is no warehouse attached to this repo. `src/synth.js` renders scenes from
a seeded PRNG and emits the ground truth alongside each frame, which is the only
reason precision and recall mean anything here.

The face is drawn rotated by a random angle up to ten degrees. That is
deliberate. Without rotation the problem collapses into an axis aligned template
match and the detector scores a perfect 1.0, which tells you nothing. With
rotation the score is 0.969 and the failures are informative.

Scenes also carry distractors: lone dark blobs shaped like a single pocket, and
dark pairs deliberately spaced too far apart to be a pallet. Those exist so the
pairing stage has something real to reject.

One thing I changed mid way. Distractors were originally placed anywhere,
including on top of the pallet face, which merged a distractor into a pocket and
dragged recall down to 0.72. Occlusion is a real problem but it is a different
problem than this detector is for, so the renderer now keeps distractors clear
of the face. That was a fix to the benchmark, not to the detector.

## Numbers

Seeds 1000 to 1099 were used while choosing thresholds. Everything below runs on
seeds 5000 and up, which the detector was never fitted against. All values are
from `results/results.json`, regenerated by `node test/run-all.js`.

| What | Result |
| --- | --- |
| Tests | 24 tests, 980 assertions, 0 failures |
| Held out accuracy (200 frames) | precision 0.9753, recall 0.9634, F1 0.9693 |
| Localisation | mean IoU 0.950 |
| Strict acceptance (IoU 0.75) | precision 0.9753, recall 0.9634, F1 0.9693 |
| Pocket level match | 88 of 92 reported pockets matched a real one (95.7%) |
| Face tilt error | 0.27 deg median, 0.29 deg mean, 0.54 deg at p90 |
| Throughput | 139.5 fps, 7.17 ms per 320x240 frame, 10.7 MP/s, single threaded |

The strict row is the one I find most interesting. Tightening the acceptance
threshold from 0.5 to 0.75 IoU does not change the score at all, which says the
detections are not scraping past the bar. They are either tight or absent.

Flat until 0.30 and then it gives way, and it gives way in the safe direction:
at 0.45 precision is 1.000 and recall is 0.731, so it stops reporting rather
than starting to lie.

## Known limitations

Rotation past about twelve degrees is where this approach runs out. The geometry
filters work on axis aligned bounding boxes, and the bounding box of a heavily
rotated pocket stops looking like the shape they expect. At eighteen degrees
recall drops to 0.50 while precision stays at 0.957, which is the same safe
direction but a real ceiling. Fixing it properly means rotated rectangles or an
oriented bounding box fit, not a wider tolerance.

One empty frame in forty also trips the pairing stage, when two dark distractors
happen to land at pocket spacing. Nothing in the pipeline currently checks that
the region between two candidate pockets is bright, which is the obvious next
guard.

Everything here is intensity only. A real fork camera would have depth, and
depth makes the pocket detection considerably easier than this.

## Where the time goes

Per 320x240 frame, averaged over 60 runs:

```
canny                 5.28 ms
gaussian blur         1.98 ms
adaptive threshold    0.42 ms
connected components  0.25 ms
```

Canny dominates and it is only used for the tilt estimate, so if the tilt is not
needed the detector runs a lot faster than 139 fps. The adaptive threshold being
cheaper than the blur is the integral image doing its job.

## Running it

```
node test/run-all.js    # tests then benchmark, writes results/results.json
node bench/bench.js     # benchmark only
```

No dependencies, no build step. Node 18 or newer.

## Layout

```
src/image.js     buffers, clamped sampling, 2d and separable convolution
src/filters.js   gaussian, sobel, non max suppression, hysteresis, canny
src/regions.js   union find labelling, region stats, integral image threshold
src/hough.js     line transform and the near horizontal tilt readout
src/synth.js     seeded scene renderer, emits its own ground truth
src/detect.js    the pipeline and the pocket pairing rules
src/evaluate.js  IoU matching, precision, recall, F1
```
